## Multi-model biomass blend — `pred_bm_mmodel`

`hls_funcs.predict.pred_bm_mmodel(dat, model, ...)` is a drop-in for `pred_bm`. It
runs the `mmodel_sel` project's *embedding-p=2* blend: predict standing herbaceous
biomass with each of five site-calibrated PLS models (CPER, Thunder Basin, FFAR
CR, FFAR MR, Jornada), then average the five per pixel by similarity in Google
Satellite Embedding space — `w_i ∝ (cos_i − row-min cos)²`, so the least-similar
model contributes nothing. Predictions are conditional medians (naive square
back-transform), biased low, exactly as `pred_bm`.

```python
from hlsstack.models.load import load_model
from hlsstack.hls_funcs.predict import pred_bm_mmodel

bundle = load_model('mmodel_biomass')          # a plain dict of numpy arrays
xr_bm = ds.map_blocks(
    pred_bm_mmodel,
    template=ds['NIR1'].astype('float32'),     # note: float32, not int16
    kwargs=dict(model=bundle),
).where(ds['NIR1'].notnull())
```

Self-contained — `hlsstack` never imports `mmodel_sel`. The five models are
distilled to coefficient vectors in `models/mmodel_biomass_bundle_<date>.pk`
(regenerated by `mmodel_sel/scripts/i_export_mmodel_bundle.py`).

**Embeddings.** The blend weights need only five cosine values per pixel. By
default `pred_bm_mmodel` reads a coarse CONUS 6-band raster shipped as package
data (`models/mmodel_similarity_conus_2km.tif`: five model-cosine bands plus a
nearest-training-neighbour `domain` band, cosine × 1e4 as int16, EPSG:5070) and
`reproject_match`es it to `dat`'s grid. Overrides:

| argument | use |
| --- | --- |
| `similarity=<path>` | a finer 5- or 6-band cosine raster for your AOI, from `mmodel_sel/scripts/b_embeddings.py --steps export --stack --aoi <vector>` |
| `similarity=<DataArray>` | an already-aligned `(model, y, x)` array (prepare once, reuse across tiles) |
| `embedding=<64-band raster/path>` | compute the cosines and domain band on the fly |

**Other arguments.** `p` overrides the weight exponent (default 2.0).
`domain_mask` (default `True`) NaNs pixels whose `domain` similarity is below
`domain_threshold` (default 0.65 — the `mmodel_sel` novelty cutoff); pass a float
to either as a shortcut, or `domain_mask=False` to fill everywhere.

**Invocation.** Like `pred_bm`, use `ds.map_blocks(...)`; a direct call needs
`time` as a single chunk (`ds.chunk({'time': -1})`). Output is `float32` (NaN
preserved) — give `map_blocks` a `float32` template.
